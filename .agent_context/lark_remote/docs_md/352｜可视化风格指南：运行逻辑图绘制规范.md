# 可视化增强：图型选择决策图

<callout emoji="💡">
**图解目标：**补充如何按内容类型选择 Mermaid 图型，方便后续 355 篇复用。
</callout>

## 1. 可视化图型选择决策图

```mermaid
flowchart TD
  Content[要表达的内容] --> Flow{是否有步骤流转}
  Flow -->|yes| Sequence{是否跨角色交互}
  Sequence -->|yes| Seq[sequenceDiagram]
  Sequence -->|no| Flowchart[flowchart TD/LR]
  Flow -->|no| State{是否有状态变化}
  State -->|yes| StateDiagram[stateDiagram]
  State -->|no| Taxonomy{是否是分类层级}
  Taxonomy -->|yes| Mindmap[mindmap or tree]
  Taxonomy -->|no| Matrix[table + small flowchart]
  Flowchart --> Review[检查节点少而准]
  Seq --> Review
  StateDiagram --> Review
  Mindmap --> Review
  Matrix --> Review
```

| 读图对象 | 图里怎么看 | 维护入口 |
|-|-|-|
| 模块职责 | 把“用什么图”标准化 | 352 风格指南 |
| 数据流 | 内容类型决定图型，再进入节点简化和验收 | Mermaid/whiteboard |
| 阅读路径 | 先判断内容，再选图型，再检查可读性 | 352 章节 |

| 场景 | 推荐图 |
|-|-|
| 请求/响应链路 | sequenceDiagram |
| 模块依赖 | flowchart TD/LR |
| 状态流转 | stateDiagram |
| 分类/层级 | mindmap 或 flowchart |
| 部署拓扑 | flowchart LR |

```mermaid
flowchart TD
  Topic[Module topic] --> Pattern{logic type}
  Pattern -->|request flow| Sequence[sequence diagram]
  Pattern -->|dependency| Flow[flowchart]
  Pattern -->|state| State[state diagram]
  Pattern -->|taxonomy| Mindmap[mindmap]
  Pattern -->|deployment| Topology[topology flow]
  AnyDiagram --> KeepSimple[keep node text simple]
```
